One-time setup

This page reads your visitor numbers straight from Cloudflare. Your API token is stored only in this browser — it never leaves your device except to ask Cloudflare for the numbers.

  1. Open Cloudflare → My Profile → API Tokens and tap Create Token.
  2. Choose Create Custom Token. Under Permissions add: Account → Account Analytics → Read.
  3. Under Account Resources choose Include → your account, then Continue to summary → Create Token.
  4. Copy the token and paste it below.
